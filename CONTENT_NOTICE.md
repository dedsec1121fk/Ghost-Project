# Content Notice / Σημείωση Περιεχομένου

<details>
<summary><strong>🇬🇧 English</strong></summary>

Ghost Project is an unofficial fan-made research and archive tool.

Call of Duty, Call of Duty: Ghosts, character names, mission names, game audio, artwork, and related game content belong to their respective rights holders.

The project does not include ripped game audio, complete campaign transcripts, complete Rorke File transcripts, game textures, or game models.

It contains original summaries, structured metadata, generated narration, and public source links.

If you add local original recordings, make sure you have the right to use or possess them.

</details>

<details>
<summary><strong>🇬🇷 Ελληνικά</strong></summary>

Το Ghost Project είναι ένα ανεπίσημο fan-made εργαλείο έρευνας και αρχειοθέτησης.

Τα Call of Duty, Call of Duty: Ghosts, ονόματα χαρακτήρων, ονόματα αποστολών, game audio, artwork και σχετικό υλικό ανήκουν στους αντίστοιχους δικαιούχους.

Το project δεν περιλαμβάνει ripped game audio, πλήρεις campaign μεταγραφές, πλήρεις μεταγραφές Rorke Files, textures ή models του παιχνιδιού.

Περιλαμβάνει πρωτότυπες περιλήψεις, οργανωμένα metadata, generated narration και δημόσιους συνδέσμους πηγών.

Αν προσθέσεις τοπικά αυθεντικές ηχογραφήσεις, βεβαιώσου ότι έχεις το δικαίωμα να τις χρησιμοποιείς ή να τις κατέχεις.

</details>
