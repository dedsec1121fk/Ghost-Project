# Gallery Images / Εικόνες Gallery

<details>
<summary><strong>English</strong></summary>

The `maps`, `weapons`, and `characters` folders contain offline JPG reference cards generated by Ghost Project from its archive data.

They are normal JPG files that can be opened by phone gallery apps, desktop image viewers, and file managers. They are not copied or ripped Call of Duty screenshots or official artwork.

Open an image from Ghost Project:

```text
image maps MAP011
image weapons W007
image characters C01
```

Export all JPG files:

```text
gallery all
```

Export one section:

```text
gallery maps
gallery weapons
gallery characters
```

On Termux, export uses the Android Pictures directory when storage access is available. On supported desktop Linux systems, export uses the user's Pictures directory.

If a card is deleted, Ghost Project can rebuild it automatically.

</details>

<details>
<summary><strong>Ελληνικά</strong></summary>

Οι φάκελοι `maps`, `weapons` και `characters` περιλαμβάνουν offline JPG κάρτες αναφοράς που δημιουργούνται από τα δεδομένα του Ghost Project.

Τα αρχεία ανοίγουν από gallery apps κινητού, desktop image viewers και file managers. Δεν είναι copied ή ripped screenshots ή official artwork του Call of Duty.

Άνοιγμα εικόνας:

```text
image maps MAP011
```

Export όλων των JPG:

```text
gallery all
```

Στο Termux γίνεται export στο Android Pictures όταν υπάρχει storage access. Σε υποστηριζόμενο desktop Linux γίνεται export στον φάκελο Pictures του χρήστη.

</details>
