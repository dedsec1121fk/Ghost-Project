# Gallery Images / Εικόνες Gallery

The `maps`, `weapons`, and `characters` folders contain offline JPG reference cards generated by Ghost Project from its archive data.

They are phone-gallery-friendly files and are not copied/ripped game screenshots or artwork.

Open an image:

```text
image maps MAP011
image weapons W007
image characters C01
```

Export all JPG files to Android Pictures:

```text
gallery all
```

Export only one section:

```text
gallery maps
gallery weapons
gallery characters
```

If a card is deleted, Ghost Project can rebuild it automatically. It installs Pillow if the image repair system needs it.

---

Οι φάκελοι `maps`, `weapons` και `characters` περιλαμβάνουν offline JPG κάρτες αναφοράς που δημιουργούνται από τα δεδομένα του Ghost Project.

Για export στο Android Pictures:

```text
gallery all
```
